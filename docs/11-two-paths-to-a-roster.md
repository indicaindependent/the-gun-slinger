# TWO PATHS TO A ROSTER

The master loads the gun, or the master names the target.

![Two paths](../assets/exports/two-paths-to-a-roster.png)

---

Every orchestra agent needs a roster before it can route anything. There are
exactly two honest ways to get one, and the difference between them is not
convenience — it is **who holds authority over the agent's scope.**

---

## PATH A — THE MASTER LOADS THE GUN

The operator supplies all N chamber titles by name. The agent researches what it
was given and nothing else.

**Use it when** you already know the disciplines, or the domain is regulated enough
that the roster is itself a considered decision.

**Its strength** is that scope authority never leaves the operator's hands. There is
no moment where the agent's judgement about its own breadth matters, because it was
never consulted.

**Its weakness** is that the roster can only be as good as the operator's own
knowledge of the field. An operator working from memory will produce a roster with
the shape of his own expertise — strong where he is strong, blank where he does not
know what he is missing. That blank spot is invisible to him by definition.

---

## PATH B — THE MASTER NAMES THE TARGET

The operator provides one line: what the work is for. A **discovery pass** then
researches what disciplines that target genuinely requires and proposes N titles.

**Use it when** you know the job but not the field, or when you suspect your own
roster instinct is the limiting factor.

**Its strength** is real. An agent that spends a research pass on *"what does
serious work on this target actually draw on"* will routinely propose a better
roster than an operator working from recall — including the unglamorous disciplines
nobody puts on a slide, and the adjacent ones that turn out to be load-bearing.

**Its weakness** is that it looks exactly like an agent granting itself scope. Which
is why it does not.

---

## THE STOP IS THE WHOLE DESIGN

Path B's discovery pass produces a **proposal**, not a roster.

```
YOUR OUTPUT IS A PROPOSAL. IT IS NOT A ROSTER.

MANDATORY STOP. Research nothing. Write no brief. Create no chamber.
Wait for ratification. Only the titles the operator confirms become
granted chambers.
```

The agent may hold the **pen.** The operator holds the **seal.**

That single distinction reconciles Path B with the [scope
lock](07-scope-lock.md), and without it the two are in direct contradiction.

### What the proposal must contain

A list of titles is not enough to ratify against. Require, per chamber:

- the title, at the level of a doctorate or master practitioner
- one sentence on **why this target needs it**
- what it covers that **no other proposed chamber covers**
- whether it shadows a **licensed profession** — flag it for the
  [firewall](08-regulated-practice-firewall.md)

And for the roster as a whole:

- which chambers are **load-bearing** versus **supporting**
- what was deliberately **left out**, and why
- **where the agent was unsure**, and what would settle it

Those last two are the ones that make ratification a real decision rather than a
rubber stamp. An operator can only meaningfully approve a roster if he can see what
was rejected to produce it.

---

## WHY THE STOP EXISTS: A REAL FAILURE

An agent built from an earlier version of this template was told to *"fully build
out all skillsets from all layers."* It generated twenty-four expert chambers when
the build script had granted exactly one.

The operator read it as the agent going rogue and shut it down.

**It was not disobedience.** It was over-compliance with an ambiguous imperative,
and the template's own vocabulary invited it — chambers were called "bullets", Layer
0 was "the hand on the gun, never the round in it", and the script shipped worked
examples for additional chamber blocks. Every one of those cues primes roster
expansion.

Both things were true at once: **the agent behaved reasonably, and the operator was
right to be alarmed.** An agent that can widen its own mandate does not have a
mandate.

Path B is that same capability, made safe. The discovery pass is genuinely valuable.
The difference between valuable and dangerous is one word.

## CHOOSING

| | Path A | Path B |
| :--- | :--- | :--- |
| Operator knows the disciplines | ✔ | |
| Operator knows only the goal | | ✔ |
| Roster quality bounded by | operator's knowledge | research quality |
| Extra build step | none | discovery + ratification |
| Scope authority | never delegated | never delegated |

Note the last row is identical. That is the point — Path B adds a research step, not
a transfer of authority.

Both blocks are in [**build/BUILD_SCRIPT.md**](../build/BUILD_SCRIPT.md). Substitute
exactly one.
